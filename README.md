# steward-reporting 🐹

> 🧭 Compliance reporting service for Steward: anonymous and named reports, officer case work, breach assessment and notification deadlines

## 📦 Install

```bash
go get github.com/Steward-GRC/steward-reporting
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
